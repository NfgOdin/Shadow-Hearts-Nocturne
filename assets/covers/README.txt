Custom Game Selection Cover Art (Shadow Hearts: Nocturne)
=========================================================

Drop your custom game selection images into this folder using these exact filenames
(.png, .jpg, .jpeg, or .webp are all supported):

  - koudelka.png   -> Koudelka (1898)
  - sh1.png        -> Shadow Hearts (1913)
  - sh2.png        -> Shadow Hearts: Covenant (1915)
  - sh3.png        -> Shadow Hearts: From the New World (1929)

Priority order:
  1. Per-user local override: games/<game>/cover.{png,jpg,jpeg,webp}
  2. Bundled artwork here:    assets/covers/<game>.{png,jpg,jpeg,webp}
